# Security Policy

## Supported Versions

Security updates are provided for the following versions of Sonora:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

Users are strongly encouraged to upgrade to the latest available release to ensure all dependencies and security fixes are up to date.

## Reporting a Vulnerability

We take the security of Sonora seriously. If you discover a vulnerability or potential security flaw, please do not disclose it publicly in an open GitHub issue.

### Preferred Reporting Method

1. Navigate to the [Security Advisories](https://github.com/asakue/Sonora/security/advisories) tab on the GitHub repository.
2. Click **Report a vulnerability** to open a private advisory draft.
3. Provide as much relevant detail as possible, including:
   - A description of the issue and potential impact.
   - Step-by-step reproduction instructions or proof-of-concept.
   - Affected versions and operating system environments.
   - Any suggested mitigations or fixes.

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours of report submission.
- **Triage and Assessment**: Within 5 business days.
- **Resolution and Patch Release**: As soon as a verified remediation is prepared and validated.

Public disclosure will occur only after a patched release is published or by mutual agreement with the reporter.
